# برنا سنسور — Hero (React + Vite + Tailwind v4)

    npm install && npm run dev

- **Fonts**: Estedad (variable, via `@fontsource-variable/estedad`). Iran Sans is licensed: put `IRANSansX.woff2` in `public/fonts/` and it becomes the display face automatically.
- **Video**: replace `src/assets/hero-loop.mp4` and `hero-poster.jpg` with your own footage (lazy-loaded on desktop only).
- **Palette**: ink `#0a1418`, steel `#12262d`, signal `#3ce0c8`, amber `#ffb547`, text `#e8f1f2` (all ≥ 8.9:1 on the dark surfaces).
- Copy, phone number and product cards are placeholders.
